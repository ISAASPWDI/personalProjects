🚀 Colección de Proyectos JavaScript Full-Stack
📋 Descripción General del Proyecto
Un conjunto completo de aplicaciones web que demuestran el desarrollo moderno de JavaScript con Node.js, Express.js y tecnologías frontend.
🛠️ Tecnologías Utilizadas

Backend: Node.js, Express.js
Frontend: HTML5, CSS3, JavaScript Vanilla
Validación de Formularios: Expresiones Regulares (Regex)
Gestión de Estado: JavaScript del lado del cliente
Estilos: CSS personalizado, Diseño Responsivo

📱 Aplicaciones Desarrolladas
1. Aplicación de Lista de Tareas

Características:

Añadir, editar y eliminar tareas
Seguimiento del estado de las tareas
Integración con almacenamiento local
Diseño responsivo



2. Aplicación de Carrito de Productos

Funcionalidades Principales:

Selección dinámica de productos
Cálculo de total del carrito en tiempo real
Seguimiento de precios individuales y totales
Interfaz de usuario intuitiva



3. Calculadora de Edad

Aspectos Destacados:

Validación de entrada de fecha
Cálculo preciso de edad
Desglose de años, meses y días
Interfaz amigable para el usuario



4. Calculadora de Impuestos

Capacidades:

Cálculos de impuestos basados en ingresos
Soporte para múltiples tramos impositivos
Desglose detallado de impuestos
Diseño responsivo



5. Formulario de Contacto

Características Robustas:

Validación integral de formularios
Verificación de entrada con Regex
Soporte para diferentes tipos de consultas
Gestión de consentimiento



🔒 Estrategias de Validación

Validación con Regex:

Validación de formato de correo electrónico
Verificación de formato de nombres
Restricciones de entrada numérica
Prevención de caracteres especiales



🌟 Logros Técnicos Clave

Arquitectura modular de JavaScript
Enrutamiento backend con Express.js
Renderizado dinámico del lado del cliente
Manejo integral de errores
Diseño responsivo y accesible

🚀 Primeros Pasos

Clonar el repositorio
Instalar dependencias: npm install
Ejecutar aplicaciones individuales: node servidor.js en los directorios respectivos

💡 Aprendizajes Obtenidos

Programación avanzada con JavaScript
Diseño de API RESTful
Técnicas de validación de formularios
Gestión de estado del lado del cliente
Principios de diseño web responsivo
